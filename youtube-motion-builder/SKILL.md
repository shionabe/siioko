# モーション構築スキル（探し方と再現のしかた）

AI は動きが苦手と言われますが、**動きの見本を見せる**と、テンポや出し方までかなり再現してくれます。
このスキルは、見本の探し方 → Claude への頼み方 → 保存して使い回す、までを一緒に進めます。

## いちばん大事な決まり（Claude へ）

1. **質問は「選んで答える」形の UI で、1回に1つ。** 選択肢を出せる道具があれば必ず使う（Claude Code・デスクトップアプリなら AskUserQuestion、claude.ai なら選択肢のボタンを出す道具）。おすすめを1つ目に置き、各選択肢に1行の説明。自由に書ける「その他」を残す。道具が無い環境では A／B／C の番号で聞く。
2. **何を決める質問かを、先に1行で言う。** 専門の言葉（イージング・キーフレーム など）だけで聞かない。
3. **探すときは、必ず検索ワードを渡す**（英語と日本語の両方・2〜4個ずつ）。`references/search_words.md` から、相手が選んだ「使う所」に合わせて選ぶ。
4. **見本をそのまま使わない。** 見本の動画・写真・ロゴ・音楽は使わず、動き（順番・タイミング・出し方）だけを真似て、相手の色・文字・素材で作り直す。
5. **作ったら、見本と左右に並べて見せる。** 「どこが違うか」をもらって直す。
6. **うまくいった動きは保存する。** 名前・見本・秒数・使い所・呼び出し方を残し、次から一言で呼べるようにする。

## 進め方

### 0. 聞き取り（選択式・1つずつ）

1. **どこで使う動きですか？**（複数可）：章の区切り／目次（今の項目を光らせる）／数字を大きく見せる／流れ図（ツールや手順がつながる）／文字の出し方（見出し・キーワード）／画面の切り替え／その他
2. **見た目の決まり（色・文字）はありますか？**：見本帳や design-system.md がある（→ 貼ってもらって読む）／まだ無い（→ youtube-design-system-builder を先にすすめる。急ぐなら今の動画のスクショから色と文字を拾う）
3. **どこで作りますか？**：Claude Code（パソコン。動画ファイル MP4 まで作れる）／claude.ai のチャット（ブラウザで動く HTML のアニメーションまで）
4. **使う編集ソフトは？**：Filmora／Premiere Pro／DaVinci Resolve／CapCut／使わない（Claude が MP4 まで）

### 1. 探す

- 「使う所」に合わせて、`references/search_words.md` から検索ワードを渡す（Pinterest・Instagram・YouTube それぞれ）
- 探し方のコツも一緒に渡す：
  - Pinterest：検索結果の動画のピンを開き、気に入ったら「保存」。似た動きが下に続くので、そこも見る
  - Instagram：モーションを発信している人をフォローし、気に入った投稿は「保存」でコレクションに
  - YouTube：気になった動きの場面は、その数秒を画面録画する
- **3〜5本集めてもらう**（1本だけより、共通する動きが分かる）

### 2. 見本を受け取って、動きを分解する

- 動画ファイル・画面録画・GIF を貼ってもらう
  - Claude Code：動画から 0.2〜0.5 秒ごとにコマを書き出して見る（ffmpeg が使える場合）
  - claude.ai のチャット：動画は中身を見られないことがある → **動きの途中のスクショを4〜6枚**（出始め・途中・止まる所）と、何秒くらいの動きかを書いてもらう
- 分解して、表で返す：**出てくる物／順番／それぞれ何秒目から何秒かけて／どう動くか（滑る・回る・弾む・ふわっと・線が伸びる）／止まり方（ピタッと・少し行き過ぎて戻る）／全体の長さ**
- 「この理解で合っていますか？」を選択式で確かめる

### 3. 依頼文を作る

- `references/request_template.md` の形で、**そのまま Claude に貼れる依頼文**を作って渡す（分解の表・見た目の決まり・長さ・書き出しの形式が入った物）
- 相手が別の会話や別の AI で作りたい場合も、この文を貼れば同じ物が頼める

### 4. 作る

- Claude Code：HTML/CSS（＋ JavaScript）でアニメーションを書き、ブラウザでコマを書き出して MP4 にする（1920×1080・30fps など相手の動画に合わせる）。Remotion などが入っていればそれでもよい
- claude.ai のチャット：HTML のアニメーションとして作り、画面で動かして見せる。動画にしたいときは画面録画してもらう
- **見本と左右に並べた物**で見せて、直す所を聞く（選択式：速さ／順番／動き方／色・文字／そのまま OK）

### 5. 保存する

- 動きの名前を一緒に決める（例：カードの回転・すりガラスのタブ・点で描く形・言葉の筒）
- `references/motion_library_template.md` の形で、**モーションの棚（motions.md）**に1行足す：名前・見本・秒・使い所・作り方のファイル
- Claude Code なら、作ったコード・MP4 を決まったフォルダ（例：`motions/`）に置く。編集用のスキルがあれば「いつもの〇〇で」で呼べるように書き足す
- 次からは「カードの回転で、章の区切りを作って」の一言で頼める

## 出来上がりのチェック（渡す前に Claude が自分で確かめる）

- [ ] 見本の写真・ロゴ・音楽を使っていない（動きだけ真似ている）
- [ ] 色・文字は相手の見た目の決まりに合っている
- [ ] 見本と左右に並べて、順番とテンポが近い
- [ ] 1つの動きが長すぎない（目安：出てくるまで 1〜2 秒、全体で 3〜5 秒）
- [ ] 依頼文に、分解の表・見た目の決まり・長さ・書き出しの形式が入っている
- [ ] モーションの棚に保存した
