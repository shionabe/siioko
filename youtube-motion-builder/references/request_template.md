# Claude への依頼文（そのまま貼れる形で渡す）

相手に渡すときは〈 〉を埋めた完成の文にする。分解の表は「2. 動きを分解する」で作った物をそのまま入れる。

## A. 再現をお願いする文（いちばん使う）

```
添付した動画の「動き」を参考に、モーションを作ってください。
見本の写真・ロゴ・音楽は使わず、動き（順番・タイミング・出し方）だけを真似て、私の見た目の決まりで作り直してください。

■ 使う所：〈章の区切り／目次／数字／流れ図／文字の出し方 など〉
■ 中に入れる物：〈文字・ロゴ・画像（例：「Chapter 02」「デザインシステム」、Claude と Filmora のロゴ）〉

■ 見本の動きの分解
| 秒 | 出てくる物 | 動き方 | 止まり方 |
|---|---|---|---|
| 0.0〜0.6 | 〈カード3枚〉 | 〈奥から手前へ回りながら〉 | 〈少し行き過ぎて戻る〉 |
| 0.6〜1.2 | 〈番号の札〉 | 〈下から滑って出る〉 | 〈ピタッと〉 |
| …… | | | |
■ 全体の長さ：〈4 秒〉（最後の 1 秒は止める）

■ 見た目の決まり
・背景：〈#F7F9E1 の霧の色→空色のグラデ〉
・文字の色：〈#204654〉／強調：〈#D6FB00 を 1 か所だけ〉
・書体：見出し〈ヒラギノ明朝〉／説明〈ヒラギノ角ゴ〉
・角の丸み：〈大きめ〉／影：〈薄いティール〉
（見本帳や design-system.md があれば、この欄の代わりに添付）

■ 書き出し
・〈1920×1080・30fps の MP4〉（claude.ai なら「ブラウザで動く HTML」）
・最後に、見本と左右に並べた確認用も作ってください
```

## B. 直しをお願いする文

```
ありがとうございます。次の所を直してください。
・〈速さ：全体をもう少しゆっくり（4 秒 → 5 秒）〉
・〈順番：番号の札は、カードが止まってから出す〉
・〈動き方：もっと弾むように／もっとなめらかに〉
ほかの所（色・文字・長さ）は今のままでお願いします。
```

## C. 保存をお願いする文

```
この動きを「〈カードの回転〉」という名前で、モーションの棚（motions.md）に保存してください。
名前・見本・秒数・使い所・作り方のファイルを1行で残して、
次から「〈カードの回転〉で〈章の区切り〉を作って」と言えば同じ動きで作れるようにしてください。
```

## D. 呼び出す文（保存したあと）

```
〈カードの回転〉で、〈章の区切り「Chapter 03 モーション」〉を作ってください。
```
