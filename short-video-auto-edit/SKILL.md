# ショート動画の半自動編集

ショート動画1本を、**台本 → 素材 → 編集 → 投稿の準備**まで、Claude が係を分けて進める。
あなた（使う人）がするのは、**方向を決めることと、仕上がりの確認**だけ。

## 0. いちばん最初に（毎回）

0. **最初に地図を見せる**：下の「1. 流れ」の8段を短く見せ、「今どの段か」と「あなたが止まるのはどこか」を伝える。段が変わるたびに「今ここ：③／8 台本と法律の壁打ち」のように1行で出す（どこまで続くか分からないと不安になるため）
1. **作業フォルダ**＝今 Claude Code で開いているフォルダ（claude.ai のチャットなら、設定ファイルの中身をチャットに書いて残す）。フォルダを開いていないときは「どこに作るか」を聞く
   ```
   作業フォルダ/
   ├─ shortvideo_settings.md   ← 設定ファイル（1つだけ）
   ├─ 20260115_仮/              ← 1本ごとのフォルダ（日付は 20260115 の形。テーマが決まったら 20260115_面接の練習/ などに付け直す）
   │   ├─ 見本/ 台本/ 素材/ 編集/ 書き出し/
   │   └─ メモ.md
   └─ …
   ```
2. 作業フォルダに `shortvideo_settings.md`（設定ファイル）があるか見る
   - **無い** → `references/01_hearing.md` の聞き取りをして、`templates/settings.md` の形で作る（最初の1回だけ）
   - **ある** → 読んで、空欄があればそこだけ聞く
3. この回のフォルダを `<日付>_仮/` で作り、中に `メモ.md`（決めたことを1行ずつ）も作る。③で切り口が決まったら `<日付>_<テーマ>/` に名前を変える
4. 下の流れのどこから始めるかを決める（「台本だけ」「編集だけ」と言われたら、その段だけ）

## 1. 流れ

| 段 | 係 | 読むファイル | できあがり | あなたが止まる？ |
|---|---|---|---|---|
| ① 聞き取り | 進行役 | `references/01_hearing.md` | 設定ファイル | 答える（最初の1回） |
| ② 見本の分析 | リサーチ | `references/02_mihon.md` | 見本の分析 MD（なぜ伸びたか・まねる所・変える所） | 見本を渡す |
| ③ 台本と法律の壁打ち | 台本 | `references/03_daihon.md` | 切り口1行 → 冒頭の言葉の案 → 台本の表 → 法律の目安チェック | **切り口と冒頭を決める** |
| ④ 素材の設計 | 素材 | `references/04_sozai.md` | 素材の表（手持ち／撮る／AI で作る／編集で描く）・撮るものリスト | **撮る・作るものを決める** |
| ⑤ 仮編集 | 編集 | `references/05_henshu.md` | 手持ちの素材と「作る物の板」を並べた仮の動画（または表） | 見て OK を出す |
| ⑥ 本編集 | 編集 | `references/05_henshu.md` | 完成の MP4／編集ソフトのファイル／並べ方の表（設定の「編集ソフト」で変わる） | — |
| ⑦ 確認 | 校閲 | `references/06_check.md` | チェックの結果（通す／直す） | **仕上がりの確認** |
| ⑧ 投稿の準備 | 投稿 | `references/07_toukou.md` | キャプション・ハッシュタグ・投稿の日時。ブラウザ操作ができる環境なら予約まで | **予約ボタンの前の OK** |

止まる所以外は、Claude が仮で決めて進め、決めたことを作業フォルダの `メモ.md` に1行ずつ残す。

## 2. 決まり（全部の段に共通）

- **言葉はやさしく**。長い一覧や表はファイルに書き、チャットは要点2〜3行と質問だけ
- 質問は選択肢（ボタン）で聞く。おすすめを1つ目に置く
- **お金（クレジット）を使う生成は、見積もりを見せてから1つずつ OK をもらう**。まとめての「OK」を生成の許可と読まない
- 投稿・送信・購入など、取り消せない操作は必ず直前に OK をもらう
- **法律の判断は「目安」**。Claude が「大丈夫です」と言い切らない。最後に決めるのはあなた（迷ったら専門家に）
- 見本は**まねる所と変える所を分ける**。映像・音楽・言い回しをそのまま写さない（著作権・アカウントの評価の両方のため）
- 人の顔・他人の商品・他社のロゴを、許可なく使わない
- ファイル名は `<日付>_<テーマ>_<中身>_v01` のように版を付け、上書きしない

## 3. あなたに直されたら

- その場で直すだけでなく、`メモ.md` の「決まったこと」に1行足す
- 同じ直しが2回出たら、設定ファイルの「自分の決まり」に足す（次の回から最初から守る）

## 4. 環境によってできること

| 使う所 | できること |
|---|---|
| Claude Code（パソコン・デスクトップアプリ） | 全部。手元の動画を読む・ffmpeg で MP4 を書き出す・ファイルを作る |
| claude.ai のチャットだけ | ①〜④と⑦の文章のチェック。⑤⑥は「並べ方の表」を渡して、編集はあなたが行う |
| ブラウザを操作できる環境（Claude in Chrome など） | ②の見本をブラウザで見る・⑧の予約投稿 |

くわしくは `references/05_henshu.md` の「編集ソフトと出口」。
