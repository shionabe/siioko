# ④ 素材の設計

台本の1カットごとに「何を映すか」を決め、**手持ちで足りる所・足りない所**を分ける。

## 順番
1. 見本の分析（②）の流れの表に、素材の**型**を付ける
   - 商品が映る／悩みの部位・肌の寄り／図解・グラフ／生活の場面／画面の録画（アプリ・サイト）／演出（暗転・文字だけ）
2. 手持ちの素材フォルダ（設定ファイル）を見て、型ごとに使えるものを探す
   - **名前だけで当てない**。コマを並べた一覧を作って、目で中身を確かめてから当てる
   ```bash
   ffmpeg -v error -y -i 素材.mp4 -vf "fps=1,scale=160:-1,tile=8x2" -frames:v 1 一覧.jpg
   ```
3. 足りない所に「新しい素材カード」を作る（下の表）
4. 素材の表（`templates/sozai.tsv`）を作る

## 新しい素材カード
| 項目 | 書くこと |
|---|---|
| 伝えること | 台本のどのカットで、何を分かってほしいか |
| 見本の見せ方 | 見本の秒と中身 |
| こちらの見せ方 | 別の被写体・比喩・構図・動き（見本をなぞらない） |
| 変える所 | 被写体／背景／構図／色／動き／比喩 のうち **3つ以上** |
| 作り方 | 撮る／AI で作る／編集で描く（下の表） |

## 作り方の分け方
| 素材の中身 | 作り方 |
|---|---|
| 商品のパッケージが映る | **撮る**（手元・顔なしでよい）。AI で文章だけから作ると文字が崩れて使えない |
| 図解・グラフ・日数・チェックリスト・強調の暗転 | **編集で描く**（お金がかからない） |
| 人物・場面のイメージ | 撮る、または AI で作る（設定で「作る」のときだけ。見積もり → OK） |
| アプリ・サイトの操作 | 画面録画 |

## 撮るものリスト
撮る素材は「何を・何秒・どの角度で・顔を出すか」を1行ずつ、チェック欄つきで渡す。

## 決まり
- 他人の顔・他社のロゴ・見本の映像を素材に使わない。出演者が出るときは、本人の同意（投稿してよいか・どこに出すか）を取っているか確かめる
- 同じ素材を何本もの動画で使い回しすぎない（見る側もサービス側も「同じ動画」と感じる）。使った素材は `素材/使った記録.tsv` に（ファイル・使った動画・日付）
- AI で作るものは、見積もり（何本・いくら・どのサービス）を見せてから1つずつ OK をもらう
