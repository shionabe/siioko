# ③ 台本と法律の壁打ち

## 順番
1. **切り口を1行で出す**（例：「日焼けを放置している人へ → 秋にシミ → 毎日続けて少しずつ」）。台本を全部書く前に方向のずれを見つけるため
2. **冒頭の言葉の案を出す**：型ごとに2〜3案
   - 名指し（「◯◯な人、これ見て」）／止める（「それ、逆効果です」）／条件（「◯◯なら、これだけで」）／問いかけ／続ける宣言（「毎日ひとつずつ紹介します」）
   - あなたが型や案を選ぶ（A/B テストするなら複数残す）
3. **台本の表を書く**（`templates/daihon.tsv` の形）
4. **法律の目安チェック**をして、引っかかった所を一覧で見せる（勝手に言い換えて済ませない）
5. あなたが決めた言い回しで仕上げる

## 台本の決まり（初期値・設定の「自分の決まり」が優先）
- 列：カット番号／秒の目安／ナレーション／テロップ／画面（何を映すか・寄りか引きか）
- **ナレーション＝テロップ**（同じ文にする。ずれると見る人が迷う）
- 1カット **12字まで**（冒頭だけ16字まで）。長い文は2カットに分ける
- 句読点（、。）は入れない（？！は可）
- 分けたカットも「画面」を空欄にしない。同じ素材でも、寄る・別の所を映す、と変化を書く
- 見せたいもの（商品・悩みの部位・手元）は**画面の中央に大きく**
- 冒頭3秒で2カット以上。同じ画が3秒を超えて続かないように

## 法律の目安チェック（商材の種類で変わる）
**ここに書くのは目安。最終の判断はあなた（迷ったら専門家・メーカーに）**。引っかかった所は「どの行・どの法律の心配・言い換えの案」で一覧にする。

| 商材 | 主に気をつける法律 | よくある心配な言い方 |
|---|---|---|
| 化粧品・医薬部外品 | 薬機法 | 「治る」「シミが消える」「ニキビに効く」など、認められた効能の範囲を超える言い方。医薬品のような言い方 |
| 健康食品・サプリ | 薬機法・健康増進法・景品表示法 | 「飲むだけで痩せる」「◯◯が改善」など体の働きへの効果。食品なのに病気や症状を名指しして「これで解決」 |
| 医療・美容施術 | 医療法（広告の決まり）・景品表示法 | ビフォーアフターの写真の扱い、「絶対」「安全」「No.1」 |
| どの商材でも | 景品表示法 | 根拠の無い数字・比較（「吸収率2倍」「No.1」）、実際と違う「今だけ」「残りわずか」「◯%OFF」 |
| PR・案件の投稿 | 景品表示法（ステルスマーケティングの規制） | 広告なのに広告と分からない。→ キャプションの「#PR」や各サービスの「プロモーション表示」で示す |
| 音楽・映像 | 著作権 | 見本の音源・映像をそのまま使う。使ってよいか（利用の条件）を確かめていない曲 |

- 症状の名前を出して「これ使え」と断定する命令の形は、いちばん心配が大きい
- 数字や比較を出すときは、裏づけ（どこの、何のデータか）をメモに残す
- 必要なら、画面の下に注意書き（「※個人の感想です」「※効果には個人差があります」「※画像はイメージです」など）を入れるかを聞く。商材に合わない注意書きをまねて入れない
