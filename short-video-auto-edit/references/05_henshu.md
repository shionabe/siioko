# ⑤ 仮編集・⑥ 本編集

## 編集ソフトと出口（設定ファイルの「編集ソフト」で決める）
スキルはどのソフトでも使える。変わるのは「最後に何を渡すか」だけ。

| 編集ソフト | Claude が渡すもの |
|---|---|
| 使わない | **完成の MP4**（ffmpeg でつなぐ・テロップ・BGM まで）。いちばん確実 |
| Premiere Pro・DaVinci Resolve・Final Cut Pro | 完成の MP4 ＋ 編集ファイル（FCPXML か XML）。ソフトで読み込んで仕上げる。※ 読み込めるかは、最初の1本で短いもので試す |
| CapCut | 完成の MP4 ＋ **並べ方の表**（カット・素材・使う秒・テロップ）。CapCut の編集ファイルは直接作らない（中身が公開されていない） |
| そのほか | 完成の MP4 ＋ 並べ方の表 |

claude.ai のチャットだけで使っている人は、手元の動画を扱えないので **並べ方の表** を渡す。

## ⑤ 仮編集（素材を作る前に）
台本と音声が決まったら、**新しい素材を作る前に**全カットを並べた仮の動画を作って見せる。動画で見れば「ここは手持ちでいい／ここは作る」がすぐ分かる。
- 手持ちで足りる所は実物を入れる
- 足りない所は色の板に「何を作るか」を大きく書く：**橙＝AI で作る／緑＝撮る／青＝編集で描く**
- テロップは台本の文字をそのまま白で（誤字の確認用）。飾り・ズーム・BGM はまだ入れない

## ⑥ 本編集
### 並べ方の表（`templates/sozai.tsv`）
カット番号／素材のファイル／使い始めの秒／終わりの秒／加工（ズーム・暗くする・黒いふち など）／テロップ

### ナレーションに合わせる
- 録音は無音を詰める（0.25秒より長い無音を詰める。詰めすぎて息つぎが不自然なら stop_duration を 0.4 に）
  ```bash
  ffmpeg -i 録音.m4a -af "silenceremove=start_periods=1:start_threshold=-38dB:stop_periods=-1:stop_duration=0.25:stop_threshold=-38dB" -ac 1 -b:a 192k ナレーション.mp3
  ```
- 文字起こし（Whisper など）の単語の時刻で、カットの切れ目を決める
- 速さを変えるときは `atempo`（声の高さは変わらない）。1.15倍・1.3倍を聞き比べて選んでもらう

### 書き出しの決まり（初期値）
- 1080×1920・30fps・音の大きさ −14〜−20 LUFS 前後（ピーク −1 dB 以下）
- テロップ：白・太い角ゴシック・うすい影、高さは全カット同じ（画面のやや上）。見せたいものにかからない
- 白や黄色の明るい背景のカットだけ、テロップに黒いふち
- ズームは画面の中央へ。左右反転は使わない（文字が鏡文字になる）
- BGM は声より約18dB 小さく、最後の1秒でフェードアウト。曲の頭に無音が無いか確かめる
- 同じ画が3秒を超えて続かない

### BGM の用意（設定ファイルの「BGM」で変わる）
| 選んだもの | やること |
|---|---|
| 投稿するサービスの曲 | 書き出しには入れない。投稿画面で付ける（TikTok・Instagram・YouTube ショートそれぞれの曲の中から）。会社・お店のアカウントは、使える曲が「商用で使える曲」に限られることがある。⑧で、どんな曲を探すとよいかを書いて渡す |
| Claude に用意してもらう | ① **理想の曲の条件**を決める → ② フリー音源を探す か AI で作る（下） |
| 自分で用意する | 曲のファイルをもらい、使ってよい曲か（利用の条件）を一緒に確かめる |
| 編集の段で決める | 仮編集を見てから、上のどれかを選んでもらう |

**① 理想の曲の条件**（台本と声に合わせて Claude が案を出す）
- 雰囲気（明るい・落ち着いた・わくわく・まじめ）、速さ（目安の BPM）、楽器、歌の有無（声とぶつかるので歌なしが基本）、長さ（尺＋数秒）、盛り上がる所の秒
- 例：「明るく前向き・BPM 110 前後・ピアノと軽いドラム・歌なし・35秒・最後の5秒で盛り上がる」

**② 曲を手に入れる**
- **フリー音源を探す**：条件に合う候補を3つほど、名前・長さ・利用の条件（商用で使えるか・名前の表示が要るか）と一緒に出す。ダウンロードは、曲名と長さを伝えて OK をもらってから
- **AI で作る**：Google の Gemini（音楽を作る機能）や、ほかの音楽を作る AI。①の条件をそのまま貼れる文にして渡す。ブラウザを操作できる環境なら Claude が作るところまで進める（お金・回数を使うものは見積もり → OK）。有名な曲のメロディをまねないと書く。作ったサービスの利用の条件（商用で使えるか）を確かめる
- 名前：`素材/BGM_<中身>_v01.mp3`。同じ曲を何本もの動画で使い回しすぎない

### 送る前に自分で確かめる
```bash
# 1秒ごとのコマを1枚に
ffmpeg -v error -y -i 完成.mp4 -vf "fps=1,scale=135:240,tile=9x4" -frames:v 1 書き出し/コマ一覧.jpg
```
- 冒頭3秒に2カットあるか／テロップが背景に消えていないか／止まった画が続かないか／商品の文字が崩れていないか／出してはいけない顔や個人の情報が映っていないか
- 当てはまったら直してから送る。送るときは「何を変えたか」を2〜3行で

### 版の名前
`書き出し/<テーマ>_v01.mp4`、直すたびに v02、v03…。古い版は `書き出し/_旧版/` へ
