# ① 最初の聞き取り

設定ファイル（`shortvideo_settings.md`）が無いときに1回だけ。答えは `templates/settings.md` の形で保存し、次の回からは聞かない。

## 聞き方の決まり
- **選ぶ項目だけボタン**で聞く。ボタンは1問に**4つまで**（下に4つ以内の選択肢を書いてある）。「分からない・まだ決めていない」は、ボタンの「そのほか」に書いてもらう
- **自由に書く項目はボタンにしない**。チャットで、番号を付けてまとめて聞く（「1. 〜 2. 〜 3. 〜 を書いてください。分からないものは『分からない』で大丈夫です」）
- **見る人・悩みは、Claude が選択肢を作らない**（作ると、例やスキルの作り手の分野に引っぱられる）。必ず書いて答えてもらう
- 例を出すときは、いくつかの分野を混ぜる（化粧品だけにしない）
- 全部聞き終えたら、設定ファイルを開いて「これで合っていますか？」と1回だけ確かめる

## 1回目：何を伝えるか
**ボタン：商材の種類**（③の法律チェックがここで変わる）
1. 化粧品・医薬部外品
2. 健康食品・サプリ・食品
3. 施術・サービス・講座・物販
4. 商品なし（ノウハウの発信）
→「そのほか」に「練習したいだけで、まだ決まっていない」と書かれたら、**練習用の架空の商品**を Claude が3案出して選んでもらう（設定ファイルに「練習用」と書く）

**書いてもらう**
1. 動画で紹介するもの（例：自分のカフェ／オンラインの英会話講座／手作りのアクセサリー）
2. ブランド名・商品名（動画やキャプションに出してよい表記で）
3. 使わないでと言われている言い方（メーカー・会社から）
4. 逆に、使ってほしいと言われている言い方・推してほしい点

## 2回目：どこに・誰に
**ボタン：投稿先**（複数選べる）：TikTok／Instagram リール／YouTube ショート

**書いてもらう**
1. 投稿するアカウント名（@〜。まだ無ければ「まだ無い」）
2. **誰に見てほしいか**（年代・暮らし・立場など）
3. **その人の悩み・ほしいこと**
4. **その人は今どうしているか**（どんなことを試している・どこで情報を探している）

**つながりを確かめる**：答えを見て「この人の悩みと、紹介するものは、こうつながります」を1行で見せる。つながらないときは、紹介するものを変えるか、切り口で結ぶかを聞く。

## 3回目：キーワード（Claude が調べて、使う人は選ぶだけ）
キーワードは**聞かない**。2回目の答えから Claude が調べてレポートにする。
- 言葉の意味は「この動画を見つけてほしい人が、TikTok などの検索のところに打ちこみそうな言葉」と説明する
- ネットで調べて **30〜50個** の案を `キーワード案.md` にまとめる（`templates/keyword_report.md` の形）
  - 悩みの種類ごとに分ける
  - 1つずつ：番号・言葉・なぜ候補か・強さの目安
  - 最後に「迷ったらこの8個」のおすすめ
- **強さは Claude の見立て**だとはっきり書く。ネットの検索では、投稿サービスの中で何回検索されているかは分からない。確かめ方も書く：投稿サービスの検索のところに打つと出る候補（サジェスト）を見る。ブラウザを操作できる環境なら、Claude が候補を拾う
- 使う人は番号で採用・削除するだけ。採用したものを設定ファイルに書く

## 4回目：どう作るか
- **使う環境は聞かない**：Claude Code で動いているなら Claude がそう書き込む。「ほかに claude.ai のチャットでも使いますか？」だけ聞く

**ボタン：編集ソフト**
1. ソフトは使わない（Claude に MP4 まで作ってほしい）
2. CapCut
3. Premiere Pro・DaVinci Resolve・Final Cut Pro
4. そのほか（「そのほか」に名前を）

**ボタン：顔出し**：自分が出る／ほかの人（出演者）が出る／出さない（手元・声だけ）／AI のキャラクター
- ほかの人が出るときは、④で「本人の同意を取っているか」を確かめる

**ボタン：ナレーション**：自分で録る／AI の声・読み上げ／ナレーションなし（テロップだけ）

## 5回目：素材と見た目
**ボタン：尺**：15秒前後／30秒前後／60秒前後

**ボタン：BGM**（くわしくは `05_henshu.md` の「BGM の用意」）
1. 投稿するサービスの曲を使う（TikTok・Instagram・YouTube ショートの投稿画面で付ける）
2. Claude に用意してもらう（理想の曲の条件を決めて、フリー音源を探す／AI で作る）
3. 自分で用意する
4. 編集の段で決める
- 1行で違いを説明する：サービスの曲は投稿画面で付けるので書き出しには入れない（会社・お店のアカウントは使える曲が限られる）。手元で動画に入れる曲は、使ってよい曲（著作権）かを確かめる

**ボタン：AI で素材を作るか**：作る／作らない
- 「作る」なら、続けて「使っているサービスは？」を1問（「まだ決めていない」も選べる）

**書いてもらう**
1. 使える写真・動画が入っているフォルダ（無ければ「無い」）
2. テロップの見た目の好きな見本（アカウントや動画の URL。無ければ設定ファイルの初期値を使う）
