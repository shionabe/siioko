# ⑧ 投稿の準備

## 作るもの
| もの | 決まり |
|---|---|
| キャプション | 1行目に見る人の悩みかキーワード（検索に出るため）。2〜4行で、動画の中身＋最後の誘い（保存・フォロー） |
| ハッシュタグ | 設定のキーワードから3〜5個。大きすぎるタグだけにしない |
| PR の表示 | 広告・案件なら「#PR」と、各サービスのプロモーション表示をオンに（動画の中の文字ではなくキャプションと設定で） |
| 投稿の日時 | 見る人が見る時間（目安：平日 19〜21時）。A/B で冒頭だけ変えた動画は同じ日に出さない |
| 曲（投稿するサービスの曲を使うとき） | 「理想の曲の条件」（`05_henshu.md`）に合う探し方（雰囲気・速さ・歌なし）を書いて渡す。サービスごとに曲の一覧が違うので、TikTok・Instagram・YouTube ショートそれぞれで選ぶ |
| カバー（表紙） | 冒頭の言葉が読めるコマを選ぶ |

## 予約投稿
- ブラウザを操作できる環境（Claude in Chrome など）なら、投稿サービスの予約画面で、動画・キャプション・タグ・日時を入れるところまで Claude がやる
- **「予約」「投稿」のボタンは、押す前に必ずあなたの OK をもらう**
- ログインやパスワードの入力は、あなたがする
- できない環境なら、キャプション・タグ・日時を1つのファイルにまとめて渡す

## 終わったら
- `メモ.md` に投稿の日時・URL を書く
- 使った素材を `素材/使った記録.tsv` に足す
- 3日後・7日後に数字（再生・保存・フォロー）を見て、伸びた理由・伸びなかった理由を `メモ.md` に1行（次の回の見本選びに使う）
