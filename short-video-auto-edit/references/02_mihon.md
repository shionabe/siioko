# ② 見本の動画の分析

伸びている見本を1〜3本もらい、「なぜ伸びたか」を分解してから台本に入る。**台本より、テロップの出し方や映像の切り替えで伸びていることが多い**ので、言葉だけを見ない。

## 見本のもらい方
- mp4 がある → そのまま使う
- URL だけ → **ダウンロードしない**（規約のため）。ブラウザを操作できる環境なら、ページで再生しながら画面を0.5秒ごとに見る。できない環境なら、あなたに画面のスクリーンショットを数枚もらう
- 見本の再生数・いいね・投稿日も控える（伸びた／伸びていないの判断に使う）

## 見本がないとき
- 採用したキーワードで投稿サービスを検索し、再生数の多い順に候補を5〜10本出す（ブラウザを操作できる環境なら Claude が探す。できなければ探し方を伝える）
- 「伸びた」の目安：そのアカウントのふだんの再生数の3倍以上、またはフォロワー数より再生数が多い
- 伸びていない動画も1〜2本見ておくと、差が分かりやすい

## コマを並べる（mp4 があるとき・Claude Code）
```bash
# 0.5秒ごとのコマを 12列×3段の一覧に（18秒ぶんで1枚）
ffmpeg -v error -y -i 見本.mp4 -vf "fps=2,scale=180:320,tile=12x3" 見本/コマ_%02d.jpg
```
一覧の画像を開いて、目で見て書く（ファイル名や字幕だけで判断しない）。

## 分析の MD（`見本/見本の分析.md`）
1. **流れの表**：秒／話していること（字幕）／映像／役割（フック・結論・説明・証拠・CTA）
2. **なぜ伸びたか**
   - 最初の1〜2秒で止める仕掛け（言葉・映像・音）
   - そのあと離れさせない仕掛け（切り替えの速さ・テロップの書体／色／大きさ／位置・強調の入れ方）
   - 最後の行動（保存・フォロー・プロフィールへ）への誘い方
3. **まねる所**：型（構成・テンポ・テロップの位置）
4. **変える所**：映像の中身・比喩・言い回し（そのまま写さない）
5. **入れない所**：法律に触れそうな言い方（③で詳しく）
