# cinematic-shot-director｜ショット・構図・カメラワークの提案（Claude のスキル）

キャラクターと背景の画像を渡して、「この人が何をするか」「どんな気持ちか」を答えるだけで、
ショットの大きさ・構図・カメラワークを2案（王道／意外な案）と理由で提案し、そのまま貼れる英語のプロンプトまで書く Claude のスキルです。

## できること
- 最初に「静止画／動画／静止画を動画に」の3つから選ぶだけ
- キャラクターシートや背景（ロケーション）の画像があれば、それに合わせてプロンプトを書きます
- 中身：カメラワーク40種・構図26種・ショット28種（大きさ9＋アングル19）
- 「ズームではなくカメラが近づく、と書く」「引くときは最後に見える物まで書く」など、AI で試して効いた書き方も入っています
- 出すのは提案とプロンプトまで。プロンプトは Seedance・Kling・Veo・ChatGPT など、どの生成 AI にも貼れる英語です

## 入れ方
- **claude.ai**：`cinematic-shot-director.skill` をダウンロード → 設定 → 機能（Skills）→ スキルを追加 → アップロード
- **Claude Code**：`cinematic-shot-director` フォルダを `~/.claude/skills/` に置く

## 使い方の例
- キャラクターと部屋の画像を添付して「動画にしたい。手紙を読んで、裏切りに気づく。胸が締めつけられる感じ」
- 「静止画で。雨の駅で、ひとり待っている。さびしい感じ」

## 注意
- 生成すると、顔や服が少し変わることがあります。変わったら作り直してください
- 光はライティングのスキル（cinematic-lighting）、色はカラーのスキル（cinematic-color-grades）と組み合わせると、さらに映画っぽくなります
