# デザインシステム構築スキル（ヒアリングシート付き）

AI に「いい感じに」と頼んでも、あなたの「いい感じ」は伝わりません。
色・文字・背景・使わない物までを**言葉にして渡す**と、初めて AI と認識がそろいます。
このスキルは、あなたが集めた参考画像から、その「言葉」を一緒に作ります。

## いちばん大事な決まり（Claude へ）

1. **画像を先に見て、画像から候補を出してから聞く。** 白紙で「好きな色は？」と聞かない。「この画像からはこう見えました。A／B／C のどれに近いですか？」と聞く。
2. **質問は1回に1つ。** 7つを一度に並べない。答えをもらってから次へ進む。答えによって次の質問の候補を変える。
3. **質問は「選んで答える」形の UI で出す。** 選択肢を出せる質問の道具があれば必ずそれを使う（Claude Code・デスクトップアプリなら AskUserQuestion、claude.ai なら選択肢のボタンを出す道具）。
   - 選択肢は2〜4個。いちばん画像に近い案を1つ目に置き、「（おすすめ）」を付ける
   - 各選択肢には短い名前（例：「月明かりの古城」）と、1行の説明（色・形・質感で何が変わるか）を付ける
   - 色・文字・カードなど見た目の質問では、選択肢ごとにプレビュー（カラーコードの並び・書体の見本の文・画面の簡単な図）を付けられるなら付ける
   - どの選択肢にも当てはまらないときのために、自由に書ける「その他」を必ず残す（道具に元からあれば足さなくてよい）
   - 複数選んでよい質問（小さな印・やらないこと）は、複数選択にする
   - 選択の道具が無い環境では、「A／B／C」の番号つきで書き、「番号だけ返事してください。違えば言葉で」と添える
   - 画像を貼ってもらう・名前を書いてもらうなど、自由な入力が要る所だけは文章で聞く
   - **毎回の質問の前に、その質問用の Pinterest の検索ワードを、英語と日本語の両方で2〜4個ずつ、文章で出す**（日本語の見本は日本語の言葉で探した方が見つかる。例：`retro typography`／「レトロ 文字 デザイン」）（これまでの答えに合わせて作る。例：印象が「夢の中の遊園地」なら、色の質問で `pastel rainbow color palette`／`dreamcore color palette`）。候補が気に入らなければ、その言葉で探した画像を貼ってもらって候補を作り直す。選択肢にも「検索して画像を足す」を入れる
4. **相手の世界観に合わせる。** このスキルに載っている例（上品・霧の色・明朝体 など）は見本にすぎない。ダーク・ポップ・かわいい・無骨など、相手の画像が示す方向をそのまま伸ばす。自分の好みや「よくあるきれいなデザイン」に寄せない。
5. **答えが曖昧なら、画像に戻る。** 「なんとなく」「おまかせ」は、画像から具体案を2〜3出して選んでもらう。
6. **色は必ずカラーコード（#RRGGBB）と「どこに使うか」の役をセットで。** 色の名前だけ・役のない色は決まりにならない。
7. **文字だけの説明で終わらせない。** 最後は必ず見本帳（HTML）で、実際の画面の型として見せる。
8. **候補に NG が出たら、理由を1行で言い換えて確かめ、その要素を外した候補を2〜3個出し直す。** 例：「明朝は和風すぎる」→「西洋の古城に日本の明朝だと時代劇っぽく見える、ということですね」→ 明朝を外した3案。出た NG は、その項目の「使わない」と「7. やらないこと」の候補に控えておく。
9. **途中で前の答えを直すのは普通のこと。** 後の質問で「暗すぎて読めないのは嫌」などが出たら、関係する前の質問（下の表）に戻って直し、「質問2の背景を #000 から #1A1D21 に直しました」のように、どこを直したかを1行で伝える。

## 進め方

### 0. 受け取る（最初の1往復）

最初に次の3つを受け取る。全部そろっていなくても始めてよい。

- **何に使うか**：チャンネル全体／動画1本／ショート・リール／スライド など。ジャンル
- **見る人**：2つの質問に分けて選んでもらう（1つの選択肢に性別と年齢を混ぜない）
  - 性別：男性が多い／女性が多い／どちらも
  - 年齢：YouTube アナリティクスと同じ区切りで、複数選択可：13〜17歳／18〜24歳／25〜34歳／35〜44歳／45〜54歳／55〜64歳／65歳以上（選択肢が4つまでの道具なら、近い区切りを2つずつまとめ、「その他」で細かく書けるようにする）
- **参考画像**：Pinterest・Instagram・好きなチャンネルのスクショ など、何枚でも。分類されていなくてよい
- **すでに決まっていること**（あれば）：チャンネル名・ロゴ・今使っている色 など

Pinterest の検索結果をまるごと撮った横長のスクショ（1枚に何十枚も入っている物）でもよい。

画像がまだ無い人には、`references/questions.md` の「Pinterest の検索ワード」を渡して、集めてから戻ってきてもらう。

### 1. 画像を読む → 「見えたこと」を返す

画像を全部見て、次の6つの観点で「見えたこと」を短く返す。これが以降の質問の材料になる。

- 世界観（どんな場所・時間・空気か。1行の比喩にする。例：「美術館の窓から明るい景色を見る」「雨のネオン街の路地裏」）
- 色（多い色・強い色・全体の明るさ・彩度）
- 形（角が丸い／尖っている／線が細い／太い）
- 質感（ざらつき・光沢・紙・金属・水彩 など）
- 文字（画像に文字があれば：太い／細い・セリフ／サンセリフ・手書き）
- 関係なさそうな画像（作業中の画面・メモ・別の話のスクショ など）があれば、外してよいかを1行で聞く。**個人の情報（名前・案件名・アドレス など）が写った画像は、見本帳に並べない**
- 画像どうしで食い違う所（例：「3枚は暗いが、2枚はパステル」）→ どちらに寄せるかを質問1で聞く

### 2. 7つの質問を1つずつ

`references/questions.md` に、7つの質問・それぞれの聞き方・画像から候補を出す方法・足りないときの検索ワードがある。必ず読んでから聞く。

| # | 質問 | 決まる物 |
|---|---|---|
| 1 | 見られたい印象（全体の雰囲気） | 世界観の1行・形容詞3つ。以降すべての物差し |
| 2 | 好きな色の組み合わせ | 5〜7色＋それぞれの役 |
| 3 | 文字の組み合わせ | 英字（アクセント・ラベル・数字）→ そのあと**日本語の見出しと字幕を別に**。日本語は Google Fonts で本人が探せる探し方と検索の言葉を渡し、候補は同じ文で並べた HTML で見せる（questions.md 3-2） |
| 4 | 小さな印（モチーフ） | 毎回置くあしらい（四隅・きらめき・テープ など） |
| 5 | 背景 | 基本の背景と、特別な所の背景 |
| 6 | カードの見た目 | 文字や画像を載せる板の形・色・影・質感。**画面の型（章の区切り・目次・数字 など）は聞かずに、Claude がジャンルから決めて見本帳で見せる** |
| 7 | やらないこと | 使わない色・効果・レイアウト（3〜5個） |

「見えたこと」を返すメッセージの最後に、質問1をそのまま続けてよい（「見えたこと」だけで1往復使わない）。各質問の後に、決まったことを1〜2行でまとめて「これで進めてよいですか？」と確かめてから次へ。

**戻る先の表**（途中でも、見本帳を見せた後でも使う）

| 言われたこと | 戻る質問 |
|---|---|
| 色が違う・派手／地味すぎる | 2 |
| 重い・軽い・雰囲気が違う | 1・5 |
| 暗すぎて読めない・まぶしい | 2・5 |
| 文字が合わない・読みにくい | 3 |
| ごちゃごちゃする・寂しい | 4・6 |
| 「これは嫌」 | 7 に足して、関係する質問も直す |

### 3. 名前を付ける

世界観から、見本帳に短い名前を付ける（英語2語くらい。例：Museum Meadow／Neon Rain／Candy Lab／Torchlit Archive）。候補を3つ出して選んでもらう。ファイル名では空白を詰める（例：`見本帳_TorchlitArchive.html`）。

### 4. 作る（2つのファイル）

1. **見本帳（いちばん大事な出来上がり）**：`見本帳_<名前>.html`。**1つの HTML ファイルで完結させる**（参考画像も data URI で中に埋め込み、別のファイルに頼らない）。保存しておけば、いつでもブラウザで開いて見返せて、そのまま人にも渡せる形にする。`references/board_template.html` を土台に、決まった色・文字・印・背景で作る。**画面の型3つは、実際の 16:9 の画面として HTML/CSS で描く**（画像を貼るだけにしない）。相手の参考画像は「読み取ったこと」の所に小さく並べてよい。
2. **Claude に渡す決まり**：`design-system.md`。`references/design-system_template.md` の形で。これを動画の編集・サムネ・スライドを頼むときに毎回貼る（またはプロジェクトの知識に入れる）。

### 5. 確かめて直す

見本帳を見てもらい、「ここが違う」をもらったら、7つのどの答えの話かに戻して直す（色が違う→質問2、重い→質問1・5 など）。直したら両方のファイルを作り直す。

## 出来上がりのチェック（渡す前に Claude が自分で確かめる）

- [ ] 色はすべて #RRGGBB と役がある。強調の色は1つ（多くても2つ）
- [ ] 文字の色と、その下の背景・面の色の**コントラスト比が 4.5 以上**（大きな見出しは 3 以上）。目で見るだけで決めず、数字で確かめる。足りない色（暗い地の赤・灰色 など）は面や線だけに使い、文字にしない
- [ ] 強調の色の上に載せる文字の色（強調の上の文字）も 4.5 以上
- [ ] 見本帳の色見本に書いた #コードと、実際の色が同じ
- [ ] 画面の型3つが、同じチャンネルの画面に見える（色・文字・角・印がそろっている）
- [ ] 「やらないこと」を見本帳の中で破っていない
- [ ] 相手の参考画像の世界観から離れていない（自分好みのきれいなデザインに寄せていない）
- [ ] 見本帳のページは、スマホの幅で横にはみ出さない（16:9 の画面の中の小さな文字は、動画の大きさ（1920×1080）で読めればよい）
- [ ] 参考画像に、関係ない画像・個人の情報が写った画像が混ざっていない
