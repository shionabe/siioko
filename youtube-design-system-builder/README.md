# youtube-design-system-builder（YouTube デザインシステム構築スキル）

AI に動画の編集を頼むときの「見た目の決まり」を、あなたが集めた参考画像から一緒に作る Claude 用のスキルです。

- 参考画像を貼ると、Claude が画像を読み、7つの質問を1つずつ候補つきで聞いてきます
- 最後に、**見本帳（HTML）** と、AI に毎回渡す **design-system.md** ができます
- 上品・ポップ・ダーク・かわいい・企業向け など、ジャンルは問いません

## 7つの質問
1. 見られたい印象（全体の雰囲気）
2. 好きな色の組み合わせ
3. 文字の組み合わせ（英字 → 日本語の見出しと字幕。日本語は Google Fonts での探し方つき）
4. 小さな印（モチーフ）
5. 背景
6. カードの見た目
7. やらないこと

Pinterest での検索ワードは `references/questions.md` の最後にあります。

## 入れ方
- **Claude（claude.ai）**：このフォルダを zip にして、設定 → スキル（プラグイン）→ アップロード
- **Claude Code**：このフォルダを `~/.claude/skills/` に置く

## 使い方
「デザインシステムを作りたい」と言って、Pinterest などで集めた画像を貼るだけです。
