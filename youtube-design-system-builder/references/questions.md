# 7つの質問（ヒアリングシート）

聞き方の基本（選択式の UI で出す。SKILL.md の決まり3）：**「画像からはこう見えました」→ 候補を2〜3個（A／B／C）→「どれに近いですか？ 違えば言葉でも OK」**。
候補は必ず相手の画像から作る。下の「例」は形を示すだけで、そのまま出さない。

---

## 1. 見られたい印象（全体の雰囲気）

- **決めること**：世界観の1行の比喩＋形容詞3つ。チャンネル全体の決まりにするか、動画1本ごとの決まりにするか
- **画像から候補を出す**：多い色・明るさ・場所・時間帯・質感から、方向の違う比喩を2〜3つ
  - 例（上品）：「美術館の窓から明るい景色を見る」＝哀愁・モダン・クール
  - 例（ダーク）：「霧の古城を、ろうそく1本で歩く」＝静か・重厚・神秘
  - 例（ポップ）：「放課後の駄菓子屋」＝にぎやか・ちょっとレトロ・人なつこい
- **画像が食い違うとき**：「暗い3枚」と「明るい2枚」など、どちらを軸にするか／混ぜるならどちらを主にするか、を聞く
- **足りないときの検索ワード**：`〇〇 aesthetic`（例：fantasy aesthetic／dreamy aesthetic／minimal aesthetic／editorial aesthetic／y2k aesthetic／dark academia aesthetic）

## 2. 好きな色の組み合わせ

- **決めること**：5〜8色。それぞれの役（背景／面＝カード・帯の地／文字／補足の文字／強調（1つ）／強調の上の文字／やわらかい強調／線・飾り／NG・失敗の印）。明るい地なら「文字」と「面の濃い色」を1色で兼ねてよい。暗い地は「背景・面・文字・補足の文字」の4つが別に要る
- **画像から候補を出す**：画像から色を拾い、「背景が明るい案」と「背景が暗い案」など、役の割り当てを変えた2案を出す。強調色は画像の中でいちばん目を引く色から
- **確かめること**：黒や赤を使うか（使うなら役を決める）。暗い地なら「真っ黒（#000）にするか、少し色のある暗さ（例：#1A1D21）にするか」。今のチャンネルに引き継ぎたい色があるか
- **文字に使う色は、背景・面とのコントラスト比 4.5 以上**（大きな見出しは 3 以上）。届かない色（暗い地の深い赤 など）は、面・線・印だけの役にする
- **検索ワード**：`color palette`／`〇〇 color palette`（例：dark fantasy color palette／pastel color palette）

## 3. 文字の組み合わせ

- **決めること**：見出し・説明・アクセント（英語1語など）・数字、の4つの役の書体と太さ
- **考え方**：太い字と細い字、セリフ（明朝）とサンセリフ（ゴシック）を組み合わせるとメリハリが出る。世界観に合わせて「手書き」「等幅」「装飾的なブラックレター」なども候補に入れる
- **画像から候補を出す**：画像の中の文字の形から。文字が無ければ世界観から
  - 上品 → 明朝＋細い斜体の欧文
  - ダーク（和：怪談・時代物）→ 太い明朝・筆文字
  - ダーク（洋：ゴシック・西洋ファンタジー）→ 日本語はゴシック（太め）にして、西洋らしさは欧文（Cinzel・ブラックレター など）に任せる。日本語の明朝は和風・時代劇に見えやすい
  - ポップ → 丸ゴシック・太い手書き
  - 企業・まじめ → ゴシック1つ＋数字だけ別の書体
- **斜体**：斜体の無い書体（Cinzel など）を傾けない。斜体はその書体に斜体があるときだけ
- **確かめること**：使う環境（Mac／Windows／編集ソフト）で使える書体か。無料で使える書体（Google Fonts など）を優先して提案する
- **検索ワード**：`editorial typography mix`／`〇〇 typography`／`font pairing`（ここまでは英字。日本語は下の 3-2）

### 3-2. 日本語の文字（見出し・字幕）— 英字とは別に決める

英字の画像（Pinterest は英語の物が多い）で決めた書体は、日本語に無いことが多い。0023 のテストでも「英語はすごい合ってるけど、日本語にしたテロップが微妙」だった。**英字が決まったら、日本語の「見出し」と「字幕（しゃべりの文字）」を別に決める。**

- **見る人が自分で探せるように、探し方を必ず渡す**（Claude が候補を出すだけで終わらせない）
  - **Google Fonts**（無料・商用 OK）：`https://fonts.google.com/?lang=ja_Jpan&preview.lang=ja_Jpan` を開く（日本語の書体だけに絞れて、見本の文も日本語になる。気になった書体は、その書体のページ（例：`https://fonts.google.com/specimen/Klee+One?lang=ja_Jpan&preview.lang=ja_Jpan`）の URL をそのまま貼ってもらえばよい。開けなければ、左の「Language」で Japanese を選ぶ）。上の「Preview」に、自分の動画の見出しの文を入れると、全部の書体がその文で並ぶ
  - その上の検索欄に入れる言葉を、決まった雰囲気から2〜4個出す（下の表）
  - Pinterest（日本語の見本）：「テロップ デザイン 〇〇」「〇〇 文字 デザイン 日本語」「〇〇 ロゴ 日本語」（〇〇＝かわいい・レトロ・ゆめかわ・ホラー など）
  - 気になった書体は、名前かスクショを貼ってもらう

| 雰囲気 | Google Fonts で入れる言葉 | 日本語の候補（例） |
|---|---|---|
| レトロ・70年代・ポップ | `retro` `pop` `rock` | RocknRoll One・Reggae One・Kaisei Decol |
| ぷっくり・かわいい | `rounded` `maru` `pop` | Darumadrop One・Mochiy Pop One・Zen Maru Gothic |
| 手書き・ゆるい | `hand` `marker` | Yusei Magic・Hachi Maru Pop・Yomogi・Klee One |
| 立体・看板 | `3D` `outline` `bold` | Rampart One・Dela Gothic One・Train One |
| 上品・雑誌 | `serif` `mincho` | Shippori Mincho・Zen Old Mincho・Kaisei Opti |
| 和風・筆 | `brush` | Yuji Syuku・Potta One |

- **見比べは HTML の1枚で**：候補を4〜6個、決まった背景・色・影の上に**同じ文**で並べて見せる（書体の名前だけでは選べない）。見出しと字幕は別の段に
- **字幕は読みやすさが最優先**：太めのゴシックか丸ゴシック。白い文字＋濃い色のふち（または帯）。見出しの書体を字幕に使わない

## 4. 小さな印（モチーフ）

- **決めること**：毎回同じ所に置くあしらい1〜3つ（四隅の枠・きらめき・テープ・ルーン文字・手描きの矢印 など）と置き場所
- **画像から候補を出す**：画像の中で繰り返し出てくる形・飾り
- **検索ワード**：`minimal sticker icons`／`〇〇 ornament`／`〇〇 doodle`

## 5. 背景

- **決めること**：いつもの背景（例：ざらつきのあるグラデーション）と、特別な所（章の区切り・締め）の背景
- **画像から候補を出す**：画像の空気感をそのまま背景にした案（グラデ・質感・ぼかした写真・柄）を2〜3つ。グラデは「背景 → 面」の近い2色が基本（強調の色を混ぜると全体が濁る）
- **確かめること**：文字が読める明るさ・暗さか。動画の録画や素材を上に置いても邪魔しないか
- **検索ワード**：`aesthetic background`／`grainy gradient background`／`〇〇 texture background`

## 6. カードの見た目

- **決めること**：文字や画像を載せる板（カード・札）の見た目。角の丸み、色（白か色付きか）、影（ふんわり／ずらした影／縁の線）、質感（つるん・粘土の立体・オーロラ・紙）
- **聞き方**：「画面の型」「レイアウト」は聞かない（0023 のテストで「何の質問？」「なんで今聞かれてるのか分からない」と言われた）。見る人が好みで選べるのは**見た目**だけ。どの画面を何枚作るか（章の区切り・目次・数字・比較・手順 など）は、Claude がジャンルと使い道から決めて、見本帳に並べて見せる。違えば見本帳を見てから直す
- **画像から候補を出す**：UI・ステッカー・パッケージの画像の、角・影・質感から
- **検索ワード**：`playful ui card design`／`y2k ui design`／`3d clay ui`／`retro sticker card`

## 7. やらないこと

- **決めること**：使わない色・効果・レイアウトを3〜5個（例：全面の黒・ネオン・赤・文字だけの画面）
- **画像から候補を出す**：1〜6で決めた方向と**逆のもの**を候補にする（上品→ネオン・極太の縁取り／ダーク→パステル・丸いポップな吹き出し）
- 大事：これがあると、AI が「よくあるデザイン」に戻るのを止められる
