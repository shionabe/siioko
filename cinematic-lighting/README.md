# cinematic-lighting｜光のプロンプト50種（Claude のスキル）

画像や動画の **光だけ** を変えて、シネマティックにするための Claude のスキルです。
窓の光・レンブラント・ネオン・月明かり・逆光・ヘイズなど50種の光から選ぶと、相手の画像に合わせた「光だけを変える」英語のプロンプトを書きます。

## できること
- 画像を Claude に入れて `/rembrandt-light` のようなコマンドを送ると、光だけを変えるプロンプトが返ってきます
- 「シネマティックにしたい」とだけ伝えると、場面に合う光を3つ提案します
- Higgsfield の MCP をつないでいれば、そのまま画像も作れます（クレジットがかかります。作る前に確認します）

## 入れ方
- **claude.ai**：`cinematic-lighting.skill` をダウンロード → 設定 → 機能（Skills）→ スキルを追加 → アップロード
- **Claude Code**：`cinematic-lighting` フォルダを `~/.claude/skills/` に置く

## 使い方の例
- 画像を添付して `/neon`
- 画像を添付して「夜の場面にしたい。シネマティックに」

## 注意
- 生成すると、顔や服が少し変わることがあります。変わったら作り直してください
- 色（ティール＆オレンジなど）は、光を決めたあとに LUT で付けるのがおすすめです（色のスキル：cinematic-color-grades）
